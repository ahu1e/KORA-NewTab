# Проверка KORA 1.4.0 — 5 сентября 2026

Проверялся рабочий каталог, без публикации. Интерфейс запускался на localhost во встроенном браузере, а не как установленное Chrome-расширение. Проверки Chrome Storage и межвкладочных сообщений расширения не являются полноценными end-to-end проверками.

## Пройдено

- Синтаксис трёх JavaScript-файлов, git diff --check, целостность ZIP.
- tests/regressions.cjs: поисковые адреса, выбор активного аудио, пауза и продолжение того же аудио, выбор музыкальной вкладки, конкурентное сохранение задач и миграция старых записей.
- Дополнительная модель плеера: next/previous вызывают соответствующие кнопки; перемотка на 50%, ограничения 0–100%, прогресс 25%.
- UI: добавление задач, синхронизация двух вкладок, отметка и удаление, сохранение после перезагрузки.
- UI: отмена заполненного диалога ссылок крестиком, добавление ссылки, сохранение после перезагрузки.
- UI: имя с HTML-символами отображается текстом; непустое имя сохраняется.
- UI: секунды, палитра, выключение подсветки, крайние значения всех восьми регуляторов сохраняются после перезагрузки.
- UI: сброс обработки и положения; загрузка PNG, сохранение и возврат стандартного фона; сообщение для чёрно-белых обоев.
- UI: режим фокуса, смена цитаты, сохранение режима Gemini, реальный переход в Google с запросом «github.com инструкция».
- В проверенных журналах страницы ошибок JavaScript не было.

## Найдено

- Настройки не закрываются по Escape: после нажатия остаётся класс settings open.
- Gemini: если кнопка отправки disabled при единственной попытке через 450 мс, повторной попытки нет. Подтверждено моделью страницы; живой сервис не проверен.

## Не подтверждено

- Живая Яндекс Музыка: в доступном браузере сайт сообщает о недоступности в регионе.
- Живой Gemini: страница не загрузилась, ошибка доступа к сайту.
- Узкий экран: запрос размера 390×844 не применился; фактическая ширина осталась 1280.
- Подбор цвета из цветных обоев, JPG/WebP, повреждённые и слишком большие файлы, переполнение хранилища, произвольный цвет через системную палитру.
- Полная работа установленного расширения с Chrome Storage и сообщениями из настоящих музыкальных вкладок.

Основной код в ходе этого прогона не изменялся. Утверждать, что абсолютно всё работает, пока нельзя.
