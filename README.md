# KORA — новая вкладка Chrome

Минималистичная персональная новая вкладка с 4K-фоном, поиском в интернете и Gemini, быстрыми ссылками, задачами, редактором изображения, настраиваемой цветовой палитрой, живой подсветкой и плеером Яндекс Музыки.

## Установка

1. Откройте в Chrome страницу `chrome://extensions`.
2. Включите «Режим разработчика» справа вверху.
3. Нажмите «Загрузить распакованное расширение».
4. Выберите эту папку.
5. Откройте новую вкладку.

Настройки сохраняются локально через Chrome Storage. KORA не собирает персональные данные. Запрос отправляется только выбранному пользователем сервису: Google Search или Gemini. Данные текущего трека читаются локально из открытой вкладки Яндекс Музыки и никуда больше не передаются.
