# KORA — новая вкладка Chrome

Минималистичная персональная новая вкладка с 4K-фоном по умолчанию, часами, поиском, быстрыми ссылками, задачами, собственными фонами и живой подсветкой, реагирующей на курсор.

## Установка

1. Откройте в Chrome страницу `chrome://extensions`.
2. Включите «Режим разработчика» справа вверху.
3. Нажмите «Загрузить распакованное расширение».
4. Выберите эту папку.
5. Откройте новую вкладку.

Данные сохраняются локально через Chrome Storage. Расширение не собирает и не отправляет персональные данные.
